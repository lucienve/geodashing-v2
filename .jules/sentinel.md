## 2024-05-18 - Fix XSS in Dashpoint Media Ledger
**Vulnerability:** Unsanitized user-supplied data (`photo.url`) was being injected directly into the `src` and `onclick` attributes of an `<img>` tag in `js/controllers.js` when rendering the dashpoint ledger. This could allow an attacker to execute arbitrary JavaScript within a victim's browser session (Stored XSS).
**Learning:** XSS can happen not just through direct text interpolation, but also via attributes like `src` or event handlers like `onclick` when embedding objects directly into the DOM as HTML strings.
**Prevention:** To prevent XSS in nested contexts (e.g., JavaScript code within an HTML attribute like `onclick`), serialize the objects securely and sanitize the dynamic data before it is injected into the DOM. This repository has a global `window.escapeHTML` utility defined in `js/app.js` specifically for this purpose, which should be used to sanitize dynamic values. For complex object structures injected into HTML strings, use the pattern `window.escapeHTML(JSON.stringify(data))`.
